# Marketing-Analytics-Automation
End-to-end marketing analytics and automation project using SQL Server, Python, and Power BI.

Marketing Analytics & Automation Dashboard
This project is an end-to-end analytics and automation solution built using SQL Server, Python, and Power BI to analyze marketing spend and sales performance across large-scale campaign data.

Tools Used
1-SQL Server
2-Python (pandas, pyodbc)
3-Power BI
4-Excel

Project Overview
1-Extracted and analyzed campaign-level marketing data using SQL.
2-Automated KPI calculations including Total Sales, Channel-wise Spend, ROI, and Average Sales using Python.
3-Built an interactive Power BI dashboard with KPI cards, spend bucket analysis, and slicers.
4-Implemented automation features such as Excel report generation, logging, and email alerts.

KPIs Calculated
1-Total Sales
2-Total Marketing Spend
3-Average Sales
4-Channel-wise Spend (TV, Radio, Social Media)
5-ROI
6-Spend Bucket Classification (Low / Medium / High)

Automation Features
1-Automated data extraction from SQL Server
2-KPI refresh using Python
3-Excel report generation
4-Logging for monitoring
5-Email alerts when sales drop below threshold

How to Run
1-Clone the repository
2-Install dependencies using pip install -r requirements.txt
3-Update database connection details
4-Run load_marketing_data.py
